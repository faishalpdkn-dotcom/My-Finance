# My Finance

## Deskripsi Project

My Finance merupakan aplikasi berbasis web untuk membantu pengguna mengelola keuangan pribadi, mencatat pemasukan dan pengeluaran, mengatur anggaran bulanan, menentukan target tabungan, serta melihat laporan keuangan secara terstruktur.

Aplikasi ini dikembangkan sebagai Tugas Besar Mata Kuliah Implementasi Perangkat Lunak (IPL) menggunakan framework Laravel dengan pendekatan arsitektur MVC (Model-View-Controller).

## Alur Kolaborasi GitHub

Setiap anggota melakukan pekerjaan sesuai pembagian tugas dengan alur berikut:

1. Clone repository.
2. Mengambil perubahan terbaru dari branch main.
3. Membuat branch sesuai tugas masing-masing.
4. Melakukan implementasi, integrasi dan pemeriksaan kode.
5. Melakukan commit dan push.
6. Membuat pull request.
7. Melakukan review dan merge ke branch main.

Ketua kelompok bertanggung jawab dalam koordinasi, pemeriksaan kontribusi dan integrasi project.
